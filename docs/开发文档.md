# 开发文档

《史莱姆牧场》一代的 NEKO 插件。默认观望，不操作游戏。按 V 进入自主经营：每个操作先瞬移到对应地点，再收食物、按围栏食性投喂、收结晶卖掉。资金达到费用两倍才建造或升级。牧场上已有无人机且程序写成功时，日常搬运交给无人机。

仓库：<https://github.com/Yangmao-123/slime-ranch-autopilot>

协作清单、环境要求和已知坑见 `docs/COLLABORATION.md`。

## 两段程序

| 部分 | 位置 | 作用 |
| --- | --- | --- |
| NEKO 插件 | `__init__.py`、`ui/panel.tsx`、`plugin.toml` | 点「启动自动游玩」才拉起核心；把 `outbox.jsonl` 转成聊天消息 |
| 自动化核心 | `core/` | 观望 / 自主经营。瞬移后用鼠标把镜头转到目标，吸取和发射走 mod |
| 游戏 mod | `bridge/SlimeBridge/` | 进游戏后在 `127.0.0.1:8124` 提供状态和动作 |

`SlimeBridge.dll` 放到游戏的 `Mods\`，由 UnityCoreMod 加载。不要打成 `.umfmod`。`Mods\SRMP.dll` 要改名为 `SRMP.dll.disabled`，否则单机高频销毁物品会打断存档。

## 模式

- `watch`：观望。不按键、不走路、不主动说话。
- `ranch`：自主经营。一轮只做一件事。

V 键在两者之间切换。Windows 优先用系统键盘钩子。切回观望会打断正在进行的操作。

自主经营的顺序：

1. 瞬移到结晶市场前。
2. 调用 `drone_setup`。成功则之后只做人出场的建造和升级。
3. 瞬移到食物旁，`vac_grab` 收入真实物品栏。
4. 瞬移到 `corral@N`，按该栏史莱姆食性 `vac_launch`，并用 `feed_show` 写入喂食器。
5. 瞬移到结晶旁吸取，再瞬移到市场，用原生经济系统结算。
6. 资金达到下一档费用两倍才建造或升级。先点菜单，点不到再走 `build` / `upgrade`。

不跑图，不抓野生史莱姆。每 8 轮调用 `save_now`。

## 安装

```bat
py -3 install.py
```

脚本把仓库复制到旁边的 `N.E.K.O\plugin\plugins\slime_ranch_autopilot`，建 `.venv-core`，编译并覆盖 `Mods\SlimeBridge.dll`。游戏必须先完全退出。然后重启 NEKO。改完插件代码后要重新生成 `plugin.meta.json`，否则面板按钮会 404。

不装游戏时：

```bat
py -3 run_standalone.py --ticks 20 --interval 0 --backend sim
py -3 -m unittest discover -s tests
```

两边用 `%TEMP%\neko-slime-ranch-autopilot\runtime` 交换 `config.json`、`command.json`、`state.json`、`outbox.jsonl`。插件启动时把旧 outbox 挪成 `outbox.prev.jsonl`。

## 改自主经营时看哪里

- 循环：`core/main_controller.py` 的 `_ranch_tick`、`_reset_to_market`、`_maybe_autosave`。
- 瞬移后的镜头和菜单点击：`core/real.py`。瞄准用相机相对的 yaw / pitch，不用 `Camera.main`。
- 两倍资金和升级次数：`core/ranch.py`。`MAX_LEVEL = 2`。
- 游戏内动作：`bridge/SlimeBridge/GameState.cs`。
  - `tp_market` / `tp_plot` / `tp_item`：先出现在目标旁边。`tp_plot` 的 `corral@N` 选第 N 个围栏。
  - `vac_grab` / `vac_launch`：原生吸取和发射。`vac_launch` 的 `corral@N` 只投这一栏吃的食物。
  - `feed_show`：把同一种食物写入喂食器。
  - `drone_setup`：`DroneGadget.SetPrograms`，并给基站补水。
  - `save_now`：`AutoSaveDirector.SaveAllNow`。

改协议必须同时改 `GameState.cs` 和 `core/bridge.py`，并在 `/api/health` 的 `features` 里登记。

## 验证

```bat
py -3 -m unittest discover -s tests
py -3 plugin_check.py
```

装进 NEKO 时目录必须是 `slime_ranch_autopilot`。涉及 C# 的改动要在说明里写「已实机验证」或「未实机验证」。
