SlimeBridge v0.5.0 —— 《史莱姆牧场》一代的游戏内桥接 mod（供 NEKO 插件「史莱姆牧场自动游玩」接入）。

【安装位 / 模组端口】
- 加载器：UnityCoreMod。把 SlimeBridge.dll 放到 <游戏目录>\Mods\。不要打成 .umfmod。
- Mods\SRMP.dll 要改名为 SRMP.dll.disabled，否则单机会打断存档。
- 编译：py -3 install.py，或 csc @build.rsp。引用游戏 SlimeRancher_Data\Managed 下的 dll。覆盖前先完全退出游戏。
- 网络端口：127.0.0.1:8124。NEKO 插件 [slime_ranch] bridge_port 必须一致。

【HTTP 契约】
- GET  /api/health   -> {"ok":true,"name":"slime_bridge","version":"0.5.0","features":[...]}
- GET  /api/status   -> 资金、设施、结晶、区域、玩家坐标
- POST /api/action   -> {"action":"<name>","kind":"<param>"}。列表放在 payload。

  感知：target / scan_corral / scan_market / scan_food / scan_plort / scan_plot / scan_facilities / ui_buttons / ui_hover
  移动：tp_market / tp_plot（corral@N 选第 N 个围栏）/ tp_item / slimes_home / drone_setup
  原生：vac_grab / vac_launch（corral@N 只投该栏食性对应的食物）/ feed_show / save_now
  诊断：probe / debug_market / debug_scene / debug_ui / debug_types / debug_cams / ammo_probe

【与 NEKO 插件的分工】
- 瞬移、吸取、发射、市场结算、无人机程序由 mod 完成。转向和点菜单由 core/real.py 用真实键鼠完成。
- 建造/升级先点游戏菜单。点不到时 build/upgrade 仍可完成购买。人会先出现在地块前。
